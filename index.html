Research

Machine Learning Algorithm for On-Board Collision Avoidance

Oscar Gledel, Noé Charpigny, Jérôme Thomassin, International Symposium on Space-Flight Dynamics (ISSFD) 2026

ALIGATOR is a machine learning based decision-making system designed for fully autonomous onboard collision risk mitigation. Its decision-making process relies on a time horizon that depends on the responsiveness of the propulsion system. It uses time series of situational data recalculated on board to support its decision. High-quality training data is crucial to ensure model’s performance and avoid biases. In this paper, we show how to address this challenge by combining real data with generated additional data using an innovative simulator. First, the simulator’s architecture and the pipeline used to generate the training data are detailled. Then, a presentation of the feature selection process for model training is done, as well as the selection of the model itself, drived by the idea of minimizing biases. Subsequently, the choice of the model is discussed starting from models that have been thoroughly studied. Finally, the initial training results are presented, demonstrating the effectiveness of the approach.

Personal projects

Physically based renderer in OpenGL

Developed during my Master's degree, this custom 3D engine focuses on photorealism and performance. It features a complete Physically Based Rendering (PBR) pipeline, a skeletal animation system using interpolated keyframes, and support for High Dynamic Range (HDR) skyboxes. Special attention was given to engine architecture and mesh management to load and render multiple complex models smoothly. The full source code is available on my GitHub.

CPU Ray Tracer (from "Ray Tracing in One Weekend")

I developed a custom CPU-based ray tracer from scratch, based on Peter Shirley's acclaimed book Ray Tracing in One Weekend. The engine features a full mathematical implementation of ray-object intersections, multi-sampled antialiasing, and recursive light bounces. It accurately simulates camera behaviors like depth of field (defocus blur) and supports various material models including dielectrics (glass), reflective metals, and Lambertian diffusers.

University Projects

Fast 2D Weyl's Discrepancy for Computer Vision

This project explores the application of the Weyl's discrepancy measure for dense stereo matching and video object tracking. To achieve near real-time performance, I implemented a highly optimized C++ engine utilizing the inclusion-exclusion principle on integral images. I pushed the optimization further by integrating low-level AVX2 vector instructions (SIMD) to process memory blocks concurrently. The algorithm was evaluated against standard baselines on disparity map generation (Middlebury datasets) and bounding box tracking, demonstrating a massive speedup over standard scalar approaches.

Adaptive Beamforming for Ultrafast Ultrasound

This Computational Imaging project aim to analyze and reproduce a state-of-the-art method for correcting phase aberrations in medical ultrasound (published in IEEE TMI, 2024). The approach relies on shifting the signal to the Radon domain using a Windowed Radon Transform and filtering noise through Tensor Rank-1 Decomposition. Beyond reproducing the original in-vivo results by porting the provided GPU code to CPU, it builds a custom simplified pipeline from scratch to deeply understand the underlying signal processing math. By simulating speckle noise on mathematical models (like the Shepp-Logan phantom), we were able to isolate and validate the precise impact of the tensor decomposition filtering.
